# Naai — Aris Remake Live2D

An independent, simplified Aris-inspired upper-body Live2D project for a future Android app.

## Current status
- [x] Remake direction and visual anchors defined
- [x] PSD layer map and Cubism parameter plan documented
- [x] Ten expression targets and five motion concepts drafted
- [ ] Separated character artwork / layered PSD
- [ ] Cubism Editor mesh and deformer rigging
- [ ] Physics tuning and expression/motion exports
- [ ] `.moc3` export and Cubism Viewer validation
- [ ] Android SDK smoke test

**Important:** This repository currently contains production specifications only. It does not yet contain finished character artwork, a PSD, texture atlas, `.moc3`, or tested Cubism runtime files. A real model requires drawing the separated artwork and completing the Cubism Editor export process.

## Remake identity anchors
- Long charcoal/navy hair with cool slate/teal highlights
- Distinctive long diagonal center fringe
- Large luminous cyan-blue eyes with digital ring highlights
- Dark headset with a teal-blue side module
- White/blue/black academy-style jacket and cyan tie

The design is simplified for practical deformation and clean animation, not intended as a pixel-perfect copy.
